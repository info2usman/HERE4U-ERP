# HERE4U ERP — Bank Maintenance, Operations & Billing System

A complete, end-to-end Enterprise Resource Planning (ERP) platform designed specifically for managing multi-branch commercial bank maintenance, repair work, field technical operations, procurement, consolidated billing, tax deductions, and payment reconciliations.

Built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS**.

---

## 🌟 Key Highlights & Modules

- 🏢 **Branch Network Master**: Complete directory of bank branches with region, contact persons, and operational status.
- 📋 **Ticket & Request Management**: Track requests from intake to execution, with one-click linking of branch complaints.
- 📐 **Estimates & Work Approvals**: Itemized cost estimates, rate breakdowns, and multi-tier approval workflows.
- 🛠️ **Work Execution & Closure**: Track technicians, site visits, field operations, delivery notes, and signed completion certificates.
- 📦 **Procurement & Inventory**: Purchase order tracking, supplier assignments, and material costing.
- 🧾 **Consolidated Billing Engine**: Group multiple branch maintenance jobs into unified corporate billing sets for bank submission.
- 💸 **Tax Deductions & Bank Receipts**: Built-in handling for withholding taxes (WHT), sales tax deductions, and partial payment allocation.
- 📊 **Job Costing & Profitability Reports**: Real-time margin calculations comparing estimated costs vs. actual expenses.
- 🔒 **Role-Based Access Control (RBAC)**: Distinct permissions for Admin, Operations Manager, Field Tech, and Accounts Officer.
- 🚀 **Hostinger Subdomain & Apache Ready**: Pre-configured with `.htaccess` rewrite rules and caching for seamless Single Page Application deployment.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS, Lucide React Icons, Motion
- **Build Tool**: Vite
- **Deployment**: Compatible with Hostinger, Apache, LiteSpeed, Vercel, Netlify, or any static web host.
